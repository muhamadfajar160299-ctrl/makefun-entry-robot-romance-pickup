A [make.fun](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) entry for **Robot Romance: One-Line Pickup Lines for AI** — one single-line joke pickup line, under 200 characters, written to charm a robot or an AI.

The line plays on the transformer architecture itself: instead of the worn-out batteries, charging and rebooting gags, it turns the model's own attention mechanism into the crush — every attention head pointing at the one it likes.

> Are you a transformer? Because ever since you showed up, all my attention heads have been pointing at you.

## How it runs

`main.py` (Python 3, stdlib only) reads `entry.txt` next to it and copies it byte-identically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (mode `0644`), with no temp files and no network.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/output python3 main.py
cat /tmp/output/entry.txt
```
